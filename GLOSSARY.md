# Worlds Through Noise

This context names the reusable learning-project concepts behind the site. The
terms are meant to survive when the same scaffold is used for a different
university course.

## Language

**Learning Project**:
A course-specific study companion built from the scaffold: one subject, one
course map, one visual identity, and one set of learning materials.
_Avoid_: Site, app, template

**Course Pack**:
The course-owned material that makes a learning project concrete: identity,
lesson order, navigation labels, calls to action, assessment wording, and the
interactive figures used by its lessons.
_Avoid_: Config, data bundle

**Lesson Grammar**:
The reusable teaching shape every concept lesson follows: name the trap, hand
over the object, make the learner perform the unseen action, then reveal the
equation and transfer check.
_Avoid_: Lesson schema, content format

**Interactive Figure**:
A manipulable visual whose readouts are computed from a model or simulation and
whose purpose is to make the unseen action physical.
_Avoid_: Chart, demo, widget

**Assessment Section**:
The course-specific practice material that closes a lesson, such as worked exam
problems, labs, derivation drills, oral prompts, or project checkpoints.
_Avoid_: Exam bank, workbook

**Worked Problem**:
A real course problem presented as a statement, parts, step-by-step solution,
and boxed result so the learner can reveal one move at a time.
_Avoid_: Example, exercise

**Course Theme**:
The visual identity of a learning project: typography, palette, semantic roles,
logo treatment, and figure styling rules.
_Avoid_: Skin, style config
