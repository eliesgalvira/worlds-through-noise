# Effect Services Orchestrate Static Learning Capabilities

Worlds Through Noise uses React for rendering, Effect services for lesson/problem/formula/progress/simulation capabilities, pure modules for deterministic math, and typed static data for educational content. This is more architecture than a small static client app strictly needs, but it keeps mathematical computation, content lookup, expected errors, progress storage, and visual simulation state in separate seams as the textbook grows from detection and estimation into filtering.
